# 🛍️ Find Your Everyday Tech

A React-based tech product browsing application that allows users to explore products, search for specific items, and sort products by price.

## ✨ Features

* 🔍 Search products
* 💰 Sort products by price
* ⚛️ Built with React.js
* 🛒 Browse tech products
* 🎨 Interactive user interface

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* React.js

## 🚀 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/aminrasooli2007-svg/find-your-everyday-tech.git
   ```

2. Open the project folder:

   ```bash
   cd find-your-everyday-tech
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🎯 Project Goal

This project was built to practice React.js, component-based development, product filtering, search functionality, and working with dynamic data.
